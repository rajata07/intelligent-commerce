# Intelligent Commerce

A planned e-commerce shopping website with an intelligent, catalog-grounded product-guidance agent.

**Status: planning only.** This repository contains the project plan and implementation backlog, not a working application. No issues have been implemented.

## Phase 1: demo MVP

Browse and search sample products, maintain a guest cart, complete a clearly labeled simulated checkout, and ask an agent for product guidance grounded in the catalog.

- Proposed stack: Next.js, TypeScript, and PostgreSQL.
- Agent integration: provider-neutral interface; the model provider is selected during implementation.
- No live payments, real fulfillment, customer accounts, or autonomous purchasing.
- Use synthetic catalog and customer data only. Never commit credentials or personal data.

See [the project plan](docs/PROJECT_PLAN.md) for architecture, roadmap, dependencies, and release criteria.

## Implementation backlog

The [Phase 1 milestone](https://github.com/rajata07/intelligent-commerce/milestones) groups the implementation issues. Each issue describes scope, acceptance criteria, dependencies, and expected verification. The Phase 1 tracking issue links the full backlog.

There are no install or run commands yet: scaffolding and developer setup are explicit backlog items.
